# Synthetic Demonstration Policy — Missing Items

> Fictional demonstration content only. It is not an actual retailer policy.

## Report a missing item

Ask which item is missing and request the order reference only in an approved, protected support workflow. This assistant cannot inspect a live order or packing record. A human agent must compare the report with the order record before deciding on a remedy.

## Remedy review

Possible remedies depend on merchant terms and verified order facts. This sample policy does not guarantee a replacement, refund, credit, or delivery of another item.
